# 短篇手艺：从一句话到最后一屏

> 用途：构思、搭节拍、写开篇/反转/结尾、写标题简介时读。这里讲“怎么让读者往下读”，不讲话术。
> 默认按番茄短故事（6000–25000 字、第一人称、手机阅读）写；其他平台按对应条目微调。

## 一、先定情绪，再定故事

短篇只服务一种主情绪。主情绪定错，后面所有技巧都会打架。

| 主情绪 | 读者读完的反应 | 常见题材 | 关键动作 |
|---|---|---|---|
| 爽感释放 | “就该这么治他” | 世情打脸、复仇、宅斗、赘婿 | 受压 → 亮牌 → 当众清算 |
| 意难平 | “明明可以……” | 追妻火葬场、错过、亲情遗憾 | 误判 → 真相 → 来不及 |
| 反转震撼 | “原来是这样” | 悬疑、身份错位、脑洞 | 误判 → 证据 → 两层真相 |
| 细思极恐 | “后背发凉” | 民俗、规则、心理悬疑 | 日常异常 → 规则 → 更大异常 |
| 治愈温暖 | “心里软了一下” | 亲情、友情、救赎、甜宠 | 裂缝 → 靠近 → 小兑现 |
| 共鸣感动 | “这说的就是我” | 婚姻、职场、原生家庭 | 具体处境 → 选择 → 代价 |

**情绪曲线**：不要从头到尾一个强度。短篇常用“压—压—爆—余”或“疑—疑—翻—凉”。每 1500 字至少让情绪换一次挡。

**一句话故事核**：

```
一个【具体身份】的人，本来只想【具体目标】，
却被【具体的人/事】夺走了【具体的东西】。
她做了一件【有代价的事】，才发现【真相】。
最后她【选择】，代价是【失去/得到】。
```

写不出这句话，说明故事还没成型；不要用“关于爱与成长”这种词糊过去。

## 二、开篇：第一屏决定生死

### 2.1 前 300 字必须完成的四件事

1. **谁**：一个可被想象的人（职业、年龄、处境）。
2. **麻烦**：正在发生，不是即将发生。
3. **赌注**：输了她会失去什么（钱、房、孩子、脸面、命）。
4. **反常**：一个让读者觉得“不对”的信息或动作。

### 2.2 五种可直接套的开局

| 开局 | 第一句长什么样 | 适合 |
|---|---|---|
| 事件炸弹 | “婆婆把月嫂辞了那天，我把房贷停了。” | 世情、复仇、追妻 |
| 反常日常 | “我妈死后第三年，她的微信运动走了 8000 步。” | 悬疑、细思极恐 |
| 审判预告 | “他们以为我不知道，房本上写的是我爸的名字。” | 第一人称打脸 |
| 对话冲突 | “‘把房子过户给你弟。’婆婆把筷子拍在满月宴的转盘上。” | 家庭、宅斗 |
| 物件悬念 | “我在丈夫西装内袋里摸到一张当票，当的是我的婚戒。” | 婚姻、悬疑 |

**禁止**：天气、城市介绍、主角完整身世、 “我叫XX，今年XX岁”、大段心理独白、先讲三年前发生的事。

### 2.3 赌注要“可量化、可截图”

不要写“她很绝望”，写“她卡里还剩 87 块，孩子的奶粉见底了”。
不要写“他背叛了她”，写“他用她的名义贷了 30 万，担保人那一栏是她签的字”。

**辨识度测试**：把主角名字换掉、地名换掉，这个开篇还成立吗？如果成立，说明太通用，加一个只有这个故事才有的细节（职业动作、方言、旧物、具体金额）。

### 2.4 开篇常见死法

- 先写 800 字“她从小生活在一个……的家庭”；
- 第一段全是环境，人物第三段才出现；
- 开头很惨，但读者不知道她想要什么；
- 开头很炸，但和后面主线无关（诈骗式开篇）；
- 用梦境/幻觉开局，读者觉得被耍。

## 三、结构：每节一个主问题

### 3.1 节拍的功能，不是字数

不管 6000 还是 18000，每一拍只干一件事：

| 拍 | 功能 | 读者此刻的问题 |
|---|---|---|
| 钩子 | 把主角按进麻烦 | “她怎么办？” |
| 受压 | 让麻烦变大，让主角按错误方式应对 | “她什么时候才反击？” |
| 一反转 | 推翻读者的第一个判断 | “等等，原来不是这样？” |
| 反打 | 主角主动出手，付出代价 | “她能赢吗？” |
| 二反转/至暗 | 更大的真相，旧办法失效 | “她还剩什么？” |
| 审判 | 当众兑现，关系结算 | “他会怎么反应？” |
| 余韵 | 留一个动作/物件/冷话 | “后来呢？”（但不解释） |

### 3.2 一节一变

每节问自己：这一节结束时，**证据、关系、风险、资源、主角的决定**，哪一个变了？一个都没变，就合并或删掉。

变盘可以很小：多了一把钥匙、少了一个证人、对方叫错一个称呼、主角第一次说谎。但不能没有。

### 3.3 节尾六种钩子

1. **新证据**：她翻开第二页，签名不是他的。
2. **新威胁**：对方发来一张她女儿放学的照片。
3. **新身份**：医生叫了她一个只有家人才知道的小名。
4. **两难选择**：救母亲还是保房子，倒计时 24 小时。
5. **反讽动作**：她笑着敬酒，把录音笔放进了对方口袋。
6. **未完成动作**：她按下发送键，屏幕显示“正在上传”。

**不要每节都靠“突然出现一个人”续命**；钩子要从前文的因果里长出来。

### 3.4 节奏口诀

长—短—短—长—短。叙述段、对话、单句段交替。连续三段长度和句式差不多，就要打散。

## 四、场景：目标—阻碍—转折—后果

一个场景不是“发生了什么”，是“谁想要什么，谁挡着，最后谁付出代价”。

```
目标：她要在满月宴上拿回房本
阻碍：婆婆当众宣布把房子给小叔子，丈夫低头不说话
转折：她拿出手机，播放三天前的录音
后果：婆婆扑过来抢手机，丈夫第一次打了她一巴掌
```

**具体锚点**：每个场景至少 2 个可以被看见/听见/摸到的东西。不是“豪华酒店”，是“转盘上的清蒸石斑鱼，鱼眼已经白了”；不是“她很穷”，是“红包里是两张皱巴巴的 20，凑不出 100”。

**五感不要全上**：一个场景选 1–2 种就够。全上会像感官清单。

**动作要有代价**：她掀桌，手被碎瓷划破；她下跪，膝盖磕在防滑垫上；她跑，拖鞋掉了一只。没有代价的动作是电视剧，不是小说。

## 五、对话：每句话都要有意图

### 5.1 六种意图

| 意图 | 台词 | 潜台词 |
|---|---|---|
| 试探 | “你最近……是不是有事？” | 我已经知道了，看你说不说 |
| 回避 | “先吃饭吧。” | 我不想谈 |
| 施压 | “你确定？再想想。” | 你不改口，后果自负 |
| 诱导 | “换我，我就签了。” | 我要你替我背锅 |
| 挑衅 | “就你？” | 我赌你不敢 |
| 敷衍 | “嗯，好。” | 我不同意，但懒得吵 |

写完一句对话，标一个意图。标不出来，删。

### 5.2 潜台词比台词重要

- “我没事。” = 我有事，但你别问。
- “你随便。” = 你最好选我能接受的那个。
- “我们还能做朋友吗？” = 我还不想放手。
- “妈说不用你管。” = 我妈不让我要你的钱，但我来了。

### 5.3 对话的技术

- **独立成行**，不嵌在叙述段里。
- 两人对话**去掉大部分标签**；三人以上才需要“谁说”。
- 用动作代替标签：“他把烟按灭在花盆里。”比“他烦躁地说”有效。
- 允许**答非所问、打断、重复、沉默**。真人说话不按提纲。
- **声纹**：每个人有固定的句长、口头禅、称呼方式。去掉名字，读者能认出谁在说。

### 5.4 对话不要承担设定说明

“你是知道的，我们家从2018年开始做建材生意，后来……”

——没有人这样说话。设定放在动作和冲突里，让读者自己拼。

## 六、反转：公平地骗，狠狠地翻

### 6.1 六种反转

| 类型 | 读者以为 | 真相 | 必备伏笔 |
|---|---|---|---|
| 身份反转 | 她是保姆 | 她是房主/失散的女儿 | 她熟悉房子的暗格、叫得出旧称 |
| 视角反转 | 丈夫出轨 | “我”才是被蒙在鼓里的人 | 结婚证日期、他不办婚礼的理由 |
| 动机反转 | 她争遗产 | 她只要一张旧照片 | 她对钱从不关心，只问老宅 |
| 时间线反转 | 两人正在热恋 | 男主已死，她在回忆里 | 外卖一人份、日历停在三年前 |
| 信息反转 | 遗嘱给长子 | 遗嘱被调包 | 见证人缺席、纸张新旧 |
| 认知反转 | 后妈刻薄 | 她用断亲保女主 | 嫁妆夹层里的银票、她故意演给外人看 |

### 6.2 公平性三原则

1. **不撒谎**：可以只露半截、可以让主角误读，但不能由叙述者直接说假话。
2. **两处伏笔**：回看前文，至少两处独立细节支持真相；最好一处在开篇 500 字内。
3. **误判参与决策**：主角因为“想错了”做过至少一个重要选择，反转才有代价。

### 6.3 双层反转

```
第一层：读者以为 A
第一层反转：其实是 B（足以暂时结案，让读者满意）
第二层：B 也只是表象，真正是 C（同时解释 A 和 B）
```

第一层后，必须写 1–2 段“主角按 B 行动”，再翻第二层。否则第二层像硬加。

### 6.4 揭示后的结算

反转不是终点。揭示后至少留一节写：
- 谁的关系变了；
- 谁付出了什么代价；
- 主角做了什么选择；
- 围观者的态度怎么翻。

只揭不结算，读者会觉得“就这？”

### 6.5 误导的四种干净手法

- **选择性叙述**：主角只盯着她以为的线索，漏掉真正重要的。
- **借真动作套假原因**：他半夜出门是真的，主角以为是偷情，其实是去医院。
- **红鲱鱼**：可疑邻居只是卤肉摊主，但他真的推了一段剧情（帮主角吓退尾随者）。
- **刻板印象**：婆婆逼儿媳把嫁妆锁进保险柜，看似刁难，实为防儿子偷去赌。

红鲱鱼必须“真的有用”，不能只是幌子。

## 七、情绪：把“惨”写成具体损失

### 7.1 损失阶梯

面子 → 钱 → 住处 → 孩子/亲人 → 命。一次只升一级，升太快会麻木。

### 7.2 羞辱要公开

私下的委屈是情绪，公开的羞辱才是事件。宴席、家族群、公司群、医院走廊、家长会、直播间——有见证人，才有“丢脸”和“出气”。

但不要为了爽让围观者全是工具人：至少给一个围观者具体的反应（低头玩手机、悄悄退群、把孩子的碗挪远）。

### 7.3 强情绪可以直接写，但要接具体东西

“我恨他”可以。下一句不能是“恨意如潮水般涌来”，要是“我把他的牙刷扔进垃圾桶，又捡回来，用来刷了马桶”。

### 7.4 虐点的分寸

- 不要连续两节纯虐；每虐一次，给一个小的反击、线索或温暖；
- 不要让主角一直哭；哭一次要有一个“哭完做了什么”；
- 不要让反派降智；反派越有理，主角的反杀越爽。

## 八、结尾：最后一句决定读者打几分

### 8.1 五种收口

| 收口 | 写法 | 适合 |
|---|---|---|
| 火葬场 | 他悔疯了，她已经不回头 | 追妻、背叛 |
| 审判金句 | “迟来的深情比草贱。” | 世情、打脸 |
| 漠视离场 | 她签完字，去赶下一场面试 | 复仇、成长 |
| 物件回环 | 开篇的婚戒，最后戴在女儿手上 | 亲情、意难平 |
| 冷幽默 | “房本是我爸的，房贷是我的，爱情是他们的。” | 世情、反讽 |

### 8.2 结尾三不要

- 不要总结人生：“她终于明白，女人要靠自己。”
- 不要强行圆满：所有坏人突然忏悔，所有伤口突然愈合。
- 不要预告续集：“然而，更大的阴谋还在等着她……”（短故事是一次性完结，硬留钩会破坏完整感）

**好结尾的标准**：最后一个画面，能让读者停两秒。不是信息量最大，是余味最长。

## 九、标题与简介

### 9.1 标题：三种可用结构

| 结构 | 例子 | 要点 |
|---|---|---|
| 具体事件 + 反常后果 | 《我把婆婆的降压药换成了维生素》 | 动作要具体，后果要悬 |
| 身份 + 冲突 + 悬念 | 《月嫂是我前夫的现任》 | 关系越不可能，越有点击 |
| 时间/数字 + 事件 | 《离婚第七天，他跪在我新家门口》 | 数字制造具体感 |

**标题自检**：
- 能不能一眼看出题材（世情/悬疑/甜宠）？
- 有没有一个具体名词（房、肾、猫、葬礼、月嫂）？
- 有没有“然后呢”的悬念？
- 会不会太长（信息流里被截断）？

### 9.2 简介：四句话

1. 身份 + 正在发生的事；
2. 一个具体的背叛/损失；
3. 一个反常的信息（读者不知道的底牌）；
4. 一句短促的尾钩。

不要写“且看女主如何逆袭”，这是 2010 年的文案。

## 十、手机端格式

- 一段只做一件事，九成段落 ≤36 字；打脸/反转/心死可单句成段。
- 对话独立成行，前后不空行（或按平台统一）。
- 不用 `**`、`#`、`---`、表格；正文不是 Markdown 文档。
- 破折号能不用就不用；省略号只放在对话里，表示犹豫/被打断。
- 章节标记统一：`###1.` 或 `###第一章`，全文只用一种。
- 不用全角空格缩进。

## 十一、六个题材的最小打法

### 世情打脸
- 核心：资源被侵占（房、钱、赔偿款、孩子学位），主角一直被当软柿子。
- 开篇：侵占正在发生，且当着外人。
- 中段：主角收集证据、稳住对方、让对手先得意。
- 高潮：当众亮证据，攻守对调；围观者态度翻转。
- 雷区：主角只会哭；反派蠢到自曝；证据来得太容易。

### 追妻火葬场
- 核心：男主把女主的付出当理所当然，女主心死后离开，男主才追。
- 开篇：一个“心死定格”事件（不是日常冷淡，是压垮的最后一根）。
- 中段：女主切割（搬家、换号、搞事业），男主误判“她只是闹脾气”。
- 高潮：男主发现真相/付出代价，女主已经不需要。
- 雷区：女主反复心软；男主一句“我错了”就复合；把虐写成家暴奇观。

### 悬疑反转
- 核心：一个错误认知，被两三条线索逐步撬开。
- 开篇：日常里的一个“不对”（时间、称呼、物件位置）。
- 中段：主角调查，每条线索都指向两个解释；第一个解释让读者满意。
- 高潮：第二个解释推翻第一个，同时解释所有伏笔。
- 雷区：靠幻觉/梦境/精神病收尾；警察全程缺席；反派自白。

### 甜宠
- 核心：关系升温的每一步都有具体事件，不是工业糖精。
- 开篇：一个被迫靠近的理由（合租、契约、工作搭档）。
- 中段：试探—误会—小兑现—再靠近；每 2–3 节一次心动点。
- 高潮：一次公开的偏爱/选择。
- 雷区：男主只会壁咚；女主只会脸红；误会靠不长嘴。

### 脑洞
- 核心：一个规则/设定，推到极致，产生荒诞又合理的后果。
- 开篇：设定第一次生效，主角是唯一发现的人。
- 中段：主角利用规则，规则反噬，代价升级。
- 高潮：用规则的漏洞翻盘，或承认自己也是规则的一部分。
- 雷区：设定说明超过 500 字；规则随剧情随便改。

### 民俗怪谈
- 核心：日常动作变成生死规则（敲门、随礼、上香、跨门槛）。
- 开篇：一条具体到动作的禁忌，加一个已经违反的人。
- 中段：规则递进，真假规则冲突，主角靠民俗逻辑破局。
- 高潮：主角按老规矩反杀，或发现“规矩”本身有问题。
- 雷区：只吓不破；规则空泛；民俗科普像论文。

## 十二、十个常见死法（编辑视角）

1. 开篇 800 字还没进入事件。
2. 主角从头到尾被动，只在心里骂。
3. 反派坏得没有逻辑，方便主角打脸。
4. 反转靠新增信息，前文零伏笔。
5. 情绪靠形容词堆，事件本身不惨。
6. 对话像论文，所有人一个腔调。
7. 每节长度差不多，节奏像列车时刻表。
8. 结尾突然升华，或突然烂尾。
9. 标题简介和正文不是一个故事。
10. 明显 AI 拼接：人名前后不一、数字对不上、时间线断裂、车轱辘话。
