# 名著库：从 100 本到 10000 本的“读过”

> 用途：用户要“像某作家”“某种感觉”“仿写”“找个参考”时，先检索再写。
> 先说清楚一件事：**没有任何模型能把 1 万本全文同时装进上下文。**
> 这个 skill 的做法不是“背全文”，而是三层记忆：**种子卡 → 风格卡 → 原文索引**。每次只取 3–5 段，够用就停。

## 一、三层记忆

| 层 | 规模 | 存在哪 | 作用 |
|---|---|---|---|
| L0 种子地图 | 100 本 | `assets/classics-seed.json` | 永远可用；每本一条“可偷的一招” |
| L1 风格卡 | 100–1000 本 | 用户自己写/生成 | 每本一页：视角、句长、对话比、意象、开篇/结尾 |
| L2 原文索引 | 1000–10000 本 | 本地 SQLite（不随 skill 发布） | 按关键词检索原文段落，取 top-k |

**上下文里永远只放 3–5 段。** 10 万字的“知识”不等于 10 万 token 的上下文；检索对了，三张卡比一万本堆着更有用。

## 二、L0：100 本种子卡

`assets/classics-seed.json` 从《名著技法地图·100 本》整理而来，每条：

```json
{
  "title": "倾城之恋",
  "author": "张爱玲",
  "category": "人物",
  "move": "白流苏出场在娘家客厅的算计里，婚姻市场即人物处境。"
}
```

人读版见 [06a-classics-map-100.md](06a-classics-map-100.md)（100 本、按技法分组）。

查询：

```bash
python scripts/classics_index.py seed --query "冷眼 婚姻" --limit 5
```

输出是“书名 + 可偷的一招”，不是情节简介。**只偷动作，不偷故事。**

## 三、L1：风格卡（每本一页）

给一本真正要仿的书做卡，不要写读后感，写“可执行参数”：

```text
【书名/作者】
【叙述距离】贴着人物 / 旁观者 / 说书人 / 不可靠
【句长】短句为主（8–15 字）/ 长句缠绕 / 长短交替
【对话比】高（>40%）/ 中 / 低（<15%）
【意象系统】雨、镜子、旧家具、食物……（只列 3–5 个）
【开篇动作】事件 / 对话 / 物件 / 格言 / 反常日常
【结尾动作】回环 / 空镜 / 冷话 / 未完成动作
【可偷的三招】
  1.
  2.
  3.
【不能学的】时代腔、专名、情节链、作者私人经验
```

风格卡不是让你“变成他”，是让你在写自己的故事时，**有三种可选的工序**。

## 四、L2：原文索引（10000 本怎么放）

把本地书库建成 SQLite 全文索引，检索时只取 top-k 段：

```bash
# 支持 .txt / .md / .docx；索引只存本地，不提交到 GitHub
python scripts/classics_index.py build --source "D:\books" --index "D:\books\classics.sqlite"

# 查 3–5 段最相关的原文
python scripts/classics_index.py query \
  --index "D:\books\classics.sqlite" \
  --query "雨 葬礼 冷眼" --limit 5

# 统计
python scripts/classics_index.py stats --index "D:\books\classics.sqlite" --top 10
```

可选元数据 `meta.json`，给文件名补作者/标签：

```json
{
  "倾城之恋.txt": {"title": "倾城之恋", "author": "张爱玲", "tags": ["世情", "婚姻", "冷眼"]}
}
```

```bash
python scripts/classics_index.py build --source "D:\books" --index "D:\books\classics.sqlite" --meta meta.json
```

**规模建议**：

- 1000 本以内：单库 SQLite 足够；按作者/题材分库也行。
- 10000 本：一个库、按 `books` 表筛作者/标签；查询只取 top 20，不要一次拉全书。
- 原文只放本地。GitHub 仓库只放种子卡、脚本和写法，不放版权文本。

## 五、仿写协议：三步，不是“洗稿”

### 第 1 步：检索（只取 3 张卡）

```bash
python scripts/classics_index.py seed --query "用户要的感觉/场景/作家" --limit 5
```

从结果里选 **3 本**，每本只取 **1 个动作**：

- 开场动作（第一句怎么签合同）
- 视角动作（谁在看、知道多少）
- 句子动作（长短、停顿、对话比）
- 物件动作（用什么承载情绪）
- 结尾动作（最后一句停在哪）

### 第 2 步：换表面，留功能

| 保留（功能） | 必须换（表面） |
|---|---|
| 信息给的早晚 | 人物姓名、身份、关系 |
| 叙述距离/视角 | 地点、时代、职业 |
| 句长与停顿 | 具体事件、对话内容 |
| 意象的“作用” | 意象本身（雨可以换成油烟/粉笔灰） |
| 结尾的“收法” | 结尾的具体动作 |

**示例**：用户要“张爱玲式的开头”，不是写上海小姐；而是：

1. 用一个**物件**开场（镜子/戒指/旧沙发）；
2. 让**婚姻市场**的算计藏在日常对话里；
3. 叙述者**冷眼**，不替人物哭。

写一个“县城相亲角/出租屋/医院走廊”的版本，人物的处境变了，工序没变。

### 第 3 步：反抄检查

```bash
python scripts/classics_index.py similarity \
  --index "D:\books\classics.sqlite" \
  --file 正文.txt --threshold 12 --strict
```

- 12 字以上连续重合：必须改。
- 只换同义词不算改；要换**动作顺序、句子结构、意象功能**。
- 没有索引时，用 `--against 原文.txt` 直接比两段。

## 六、六个“快速反应”配方

| 用户说 | 先检索 | 偷什么 | 不要做什么 |
|---|---|---|---|
| “张爱玲式开头” | 张爱玲 / 王安忆 / 萧红 | 物件开场、婚姻市场、冷眼反讽 | 不要写上海腔、不要堆“苍凉” |
| “海明威式对话” | 海明威 / 卡佛 | 短句、重复、冰山省略 | 不要故意装硬汉、不要每句都短 |
| “马尔克斯式雨” | 马尔克斯 / 莫言 | 时间折叠、魔幻当日常陈述 | 不要堆“多年以后”句式 |
| “鲁迅式看客” | 鲁迅 / 萧红 | 小伙计视角、不解释、留白 | 不要直接骂“国民性” |
| “悬疑开场” | 加缪 / 芥川 / 奥威尔 | 反常日常、信息差、冷陈述 | 不要靠幻觉/梦境 |
| “世情打脸” | 张爱玲 / 老舍 / 余华 | 物件算账、当众羞辱、冷收 | 不要反派降智、不要总结人生 |

## 七、边界与法律

- **只仿结构功能，不抄表达**：句子、专名、情节链、独特意象组合，都不搬。
- **版权**：原文索引只放本地；种子卡只含技法摘要与 ≤50 字必要引文；公开仓库不放版权文本。
- **不冒充**：交付时说“结构参考自 X 的 Y 动作”，不说“这是 X 写的/未发表遗稿”。
- **不编造**：没有索引就说“用 100 本种子卡”；没读过某本，不要编引文和情节。
- **不堆术语**：不要说“互文性/解构/零度写作”，直接说“第一句先给结果，第三段才解释”。

## 八、质量门

仿写段落交付前：

- [ ] 只用了 3 个动作，不是把 3 本书缝成一件百衲衣
- [ ] 人物、地点、事件至少换了两样
- [ ] 没有 12 字以上连续重合（`similarity --strict`）
- [ ] 没有搬专名、独特意象组合、原情节链
- [ ] 读起来像“这个故事本来就会这样写”，不是“作者在模仿谁”
- [ ] 跑过 `check_ai.py`，没有模板腔阻断项

---

**一句话**：名著库不是让你“像别人”，是让你在卡住的时候，有 10000 种**工序**可选；最后写出来的，必须还是你自己的故事。
