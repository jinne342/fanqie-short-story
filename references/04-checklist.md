# 终检与过稿诊断

> 用途：投稿前、交付前、帮用户诊断时。按门顺序过；结构问题没解决，不要先抠字句。

## 门 0：交付参数

- [ ] 目标平台/频道写明（番茄短故事）
- [ ] 目标字数写明（6000 / 1.2万 / 1.8万 / 2.5万+）
- [ ] 人称、题材、主情绪、结局类型写明
- [ ] 是否用户指定了文风/参考作品/禁用写法
- [ ] 是否涉及真实人物、真实事件、敏感职业（医疗/法律/未成年）

参数没定，后面所有“好坏”都是空的。

## 门 1：平台门（不过则一票否决）

- [ ] 非空白字数 ≥6000（短故事签约线）；目标 1万–1.8万最佳
- [ ] 开篇 300 字内出现具体的人、具体的麻烦、具体的代价
- [ ] 标题能看出题材 + 有一个具体名词 + 有悬念
- [ ] 简介与正文第一段咬合，没有“且看女主如何逆袭”
- [ ] 正文无 Markdown 符号、无乱码、章节标记统一
- [ ] 无同人无授权、无洗稿、无真实他人隐私
- [ ] 校园暴力/灵异/犯罪过程按保守尺度处理
- [ ] 没有“前 10 章人工、后文 AI 灌水”式断裂

## 门 2：故事门

### 2.1 开篇

- [ ] 第一句是事件/对话/反常，不是天气/身世/心理
- [ ] 读者 3 屏内知道：谁、想要什么、输不起什么
- [ ] 赌注可量化（钱、房、孩子、期限、命）
- [ ] 开篇的麻烦与主线强相关，不是诈骗式开头
- [ ] 有一个“只有这个故事才有”的细节

### 2.2 中段

- [ ] 每节一个主问题；节尾有变盘
- [ ] 每 1500 字至少一次信息/关系/风险/资源/决定的变化
- [ ] 损失阶梯在升（面子→钱→住处→亲人→命），没有原地打转
- [ ] 主角至少做了 1 个主动、不可逆、有代价的选择
- [ ] 反派有合理动机，不是纯工具人
- [ ] 没有连续两节同一情绪强度

### 2.3 反转

- [ ] 反转类型清楚（身份/视角/动机/时间线/信息/认知）
- [ ] 回看能找到 2 处独立伏笔，其中 1 处在开篇 500 字内
- [ ] 主角的误判参与过至少 1 次重要决定
- [ ] 没有靠旁白撒谎、幻觉、精神病、反派自白收尾
- [ ] 揭示后至少 1 节写行动/关系/代价结算
- [ ] 双层反转之间，主角按第一层真相做过行动

### 2.4 结尾

- [ ] 最后一个画面/动作有余味，不是人生总结
- [ ] 该兑现的当众兑现，该结算的关系结算
- [ ] 没有突然忏悔、突然圆满、突然续集钩
- [ ] 结尾与开篇的物件/动作有回环（加分项，非必须）

## 门 3：人味门

### 3.1 机器扫描

```bash
# 在 skill 根目录执行；当前目录不是 skill 根目录时，换成脚本绝对路径
python scripts/check_ai.py 正文.txt --min-words 6000
```

- [ ] 无“阻断”项
- [ ] 模板腔指数 ≥75（B 级以上）
- [ ] 阻断项逐条人工确认：是功能句还是模板句？功能句登记白名单，模板句改写
- [ ] 建议项不追求清零，只改“删掉不损失信息”的

### 3.2 语义十问（至少 8 问通过）

1. 这一节谁想要什么？要不到会怎样？
2. 主角做了什么选择？代价是什么？
3. 这一节结束时什么变了？
4. 哪个细节是这篇独有的？
5. 叙述者的偏见/盲区在哪里？
6. 有没有生活噪音或身体感？
7. 对话有潜台词吗？去掉名字能认出人吗？
8. 反转伏笔回看能找到两处吗？
9. 有没有一段是在“解释”而不是“发生”？
10. 最后一段是在讲故事，还是在讲道理？

### 3.3 朗读

- [ ] 出声读一遍，没有想跳过的地方
- [ ] 没有连续 3 句以上同样节奏
- [ ] 没有读起来像新闻联播/论文摘要的段落
- [ ] 删掉了至少 10% 的形容词、解释、重复情绪

## 门 4：交付门

- [ ] 错别字、的地得、人名/地名/数字前后一致
- [ ] 引号全半角统一；对话独立成行
- [ ] 段落之间空行规则统一
- [ ] 章节标记统一（`###1.` 或 `###第一章`，不混用）
- [ ] 标题/简介/正文里的名字、关系、金额一致
- [ ] 文件编码 UTF-8；文件名与标题一致

## 100 分评分表（自评/诊断用）

| 维度 | 分值 | 满分标准 | 常见扣分 |
|---|---|---|---|
| 开篇 | 20 | 第一屏有事件、赌注、反常；删不掉任何一句 | 背景铺垫、天气、身世 |
| 情绪 | 20 | 主情绪明确；损失具体；有 1–2 处能截图 | 形容词堆砌、情绪重复 |
| 结构 | 20 | 每节变盘；损失阶梯上升；结尾有结算 | 中段原地打转、节尾无钩 |
| 反转 | 15 | 公平、有两处伏笔、揭示后有行动 | 靠新信息硬翻、无结算 |
| 人味 | 15 | 具体锚点、叙述者偏见、对话有潜台词 | 模板句、人物同声、均匀 |
| 格式 | 10 | 手机端可读、标点统一、无 Markdown | 长段、空行乱、符号混入 |

**判定**：
- ≥85：可投；重点检查标题/简介和红线。
- 75–84：可投但建议精修；优先修开篇和中段变盘。
- 60–74：需要一轮结构级修改，不要直接投。
- <60：重写，不要逐句润色。

## 修改优先级（从高到低）

1. **故事核**：主角想要什么、输不起什么、最后选了什么。核不对，改字没用。
2. **结构**：开篇是否进事件、每节是否变盘、反转是否公平、结尾是否结算。
3. **人物**：主角是否主动、反派是否有逻辑、配角是否有功能。
4. **场景**：目标—阻碍—转折—后果是否成立；有无具体锚点。
5. **句子**：词表、句式、比喻、节奏。
6. **标点/格式**：最后一遍。

**不要**在结构没解决时逐句润色；也不要用“文笔好”掩盖“故事没发生”。

## 过稿诊断输出模板

```
【目标】番茄短故事 / 1.2 万字 / 世情反转
【结论】可投 / 需修 / 建议重写
【三处致命伤】
1. 位置：开篇第 2–5 段
   问题：先讲三年前身世，第 600 字才进事件
   改法：把“满月宴宣布房子给小叔子”提到第一段；身世压成两句，放到第 3 节
2. ……
3. ……
【平台风险】字数 / 标题 / 红线 / 格式
【人味分】78（B）/ 阻断 0 / 建议项 6
【最小改动清单】只列 3–5 条，按优先级
```

## 编辑最常见的 10 个拒稿理由

1. 开篇铺垫太长，第 500 字还没进事件。
2. 主角全程被动，只有心理活动，没有选择。
3. 情绪靠形容词，事件本身不惨/不爽。
4. 反转没有伏笔，靠新增人物或新信息硬翻。
5. 反派降智，打脸像打空气。
6. 中段重复，同一个矛盾吵三节。
7. 对话像论文，所有角色一个腔调。
8. 结尾升华/烂尾/硬留续集钩。
9. 标题简介与正文不是一个故事。
10. 明显的 AI 拼接：人名前后不一、数字对不上、时间线断裂、车轱辘话。

---

**交付前最后一眼**：把开篇 300 字和结尾 200 字单独拎出来读。这两段立不住，中间写再好也白搭。
