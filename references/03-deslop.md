# 去 AI 味：从“像模型写的”到“像人写的”

> 用途：初稿完成后、投稿前。核心不是删词，是**换掉模型的默认选择**：均匀、解释、安全、无偏见、无代价。
> 先读一遍，再跑 `scripts/check_ai.py`，然后按“机械遍 → 语义遍 → 朗读遍”改。

## 〇、先纠三个误区

1. **去 AI 味 ≠ 骗过检测器**。检测器有误报，平台真正打击的是低质、空洞、断裂。文本有具体信息、有因果、有活人声音，才是终点。
2. **去 AI 味 ≠ 同义词替换**。把“仿佛”换成“好似”、把“缓缓”换成“慢慢”，模型腔还在。要换的是**信息组织方式**。
3. **去 AI 味 ≠ 加错别字、加脏话、把句子全打碎**。那是噪音，不是人味。真人写作也有完整长句、也有总结、也有漂亮比喻，只是**不匀、不空、不躲**。

## 一、AI 味的四个来源

| 来源 | 表现 | 人味的方向 |
|---|---|---|
| **均匀** | 段一样长、句一样长、每节节奏一样、情绪强度一样 | 长短交错；该短则短，该拖则拖 |
| **解释** | 每个情绪都命名，每个动作都解释动机，每段开头先总结 | 让动作和物件说话；留白；让读者自己拼 |
| **安全** | 比喻用“水/火/风”，形容词用“美丽/温柔”，冲突用“误会—解释—和好” | 具体、意外、角色化的比喻；真实的恶意和私心 |
| **无偏见** | 叙述者像摄像机，对谁都很公允；人物说话一个腔调 | 叙述者有立场、有盲区、有说不出口的话 |

一句话：**模型选“在最多情况下都说得过去”的表达；人要选“只有这个人在这个时刻才会说/做”的表达。**

## 二、词层：先清最明显的指纹

> 不是绝对禁用。角色因身份说、全文只出现一次、有功能，可以留。判断标准：删掉它，信息或情绪有没有损失？

### 2.1 总结概括词（叙述层几乎必删）

`总而言之 / 综上所述 / 总的来说 / 不言而喻 / 毋庸置疑 / 毫无疑问 / 归根结底 / 说到底 / 本质上 / 值得注意的是 / 需要指出的是 / 一言以蔽之 / 简而言之`

**改法**：删掉，直接说结论；或把结论变成一个动作。

### 2.2 书面连接词（小说里显得假）

`首先…其次…最后 / 一方面…另一方面 / 不仅…而且…更 / 既…又…还 / 因此 / 从而 / 继而 / 与此同时 / 在此期间 / 换言之 / 也就是说 / 事实上 / 实际上 / 众所周知`

**改法**：用场景切换、动作、对话连接。删掉 80% 的“因此/于是”，读者照样看得懂因果。

### 2.3 情绪直述（AI 最爱）

`感到震惊 / 感到愤怒 / 感到悲伤 / 内心充满了XX / 心中涌起一股XX / 不禁感到 / 一种XX的感觉油然而生 / 百感交集 / 五味杂陈 / 心如刀割 / 心如死灰 / 撕心裂肺`

**改法**：换身体反应、换动作、换一个具体物件。不是“她很委屈”，是“她把那碗汤端回厨房，倒掉，又觉得可惜，端回来自己喝了”。

**例外**：番茄虐爽题材允许直接写情绪词（“我恨他”“我彻底死心”），但后面必须接具体动作，且同一情绪不重复解释。

### 2.4 套式动作

`缓缓开口 / 缓缓说道 / 淡淡地说 / 沉声道 / 微微一笑 / 淡淡一笑 / 嘴角微微上扬 / 勾起一抹弧度 / 眉头微皱 / 眉头紧锁 / 深吸一口气 / 目光如炬 / 目光深邃 / 眼底闪过一抹XX / 指节泛白 / 身形一滞 / 脚步一顿 / 不由自主地 / 情不自禁地`

**改法**：写清楚“怎么笑/看哪里/手在干什么”。每章“深吸一口气”最多 1 次；连续两个套式动作必须拆。

### 2.5 套式环境

`月光如水 / 月光倾泻 / 阳光明媚 / 阳光灿烂 / 微风拂面 / 清风徐来 / 万籁俱寂 / 鸦雀无声 / 如诗如画 / 美不胜收 / 璀璨 / 瑰丽 / 绚烂 / 宛如仙境`

**改法**：写这个场景里**具体的**光、声、气味、温度，以及它和人物的关系。不是“月光如水”，是“月光从防盗窗的方格里漏进来，在地上切成四块”。

### 2.6 弱化副词（“微微系列”）

`微微 / 淡淡 / 缓缓 / 轻轻 / 悄然 / 默默 / 隐隐 / 些许 / 一丝 / 一抹 / 几分 / 隐约`

**标准**：每千字超过 6 个就是模板腔。删大部分；剩下的是真的需要“微弱程度”的地方。

### 2.7 抽象大词

`命运 / 宿命 / 灵魂 / 岁月 / 时光 / 人生 / 尊严 / 救赎 / 羁绊 / 执念 / 众生 / 尘埃 / 光 / 深渊`

**改法**：不是不能写，是不能**拿它们当解释**。把“命运的齿轮开始转动”换成“他把那份调令压在茶杯底下，没让她看见”。

### 2.8 四字成语堆叠

`心潮澎湃、热血沸腾、激动万分` / `恍然大悟、如梦初醒、茅塞顿开` / `不由分说、二话不说、当机立断`

**标准**：每 500 字 ≤3 个；连续两个以上必须拆。四字连用是 AI 最明显的节奏指纹之一。

### 2.9 翻译腔

`对自己感到满意 / 感到被冒犯 / 做出一个决定 / 给予回应 / 进行了一次谈话 / 有着一种……的感觉 / 某种程度上 / 在某种意义上`

**改法**：换成中文的动作和口语。“他做出一个决定” → “他决定了”；“进行了一次谈话” → “他找她谈了一次”。

## 三、句层：六个高频模板

### 3.1 “不是 A，而是 B”

AI 最爱用它制造“深刻感”。

- ❌ 这不是一场普通的婚礼，而是一场精心设计的骗局。
- ✅ 婚礼进行到一半，我才发现迎宾牌上的新娘名字被换过。底下那层没撕干净，露出一个“周”字。

**改法**：删掉否定铺垫，直接写后项；或把“不是/而是”变成两个具体证据。

### 3.2 三连排比

- ❌ 她失去了爱情，失去了家庭，失去了尊严。
- ✅ 她失去了那套房子。至于爱情，早在去年冬天他把她一个人丢在高速服务区时就没了。

**标准**：每个三连都做“删一项测试”；删掉不损失信息，就删。有递进功能的三连可以留（“在暴雨夜、在手术室门口、在我爸的葬礼上”）。

### 3.3 否定排比

- ❌ 没有婚礼，没有戒指，没有祝福。
- ✅ 婚礼没办。戒指是他妈留下的旧款，大了两号。那天只有她同事来了，随了 200 块。

**改法**：把“没有X”换成“实际发生了什么/有什么”。

### 3.4 对仗/对称句

- ❌ 他越是沉默，她越是心慌；他越是冷静，她越是绝望。
- ✅ 他不说话。她开始数他衬衫上的扣子，数到第三遍，他还是不说话。

**改法**：打破对称，让一句比另一句长，或让第二句变成一个具体动作。

### 3.5 解释链

- ❌ 她知道，这意味着他早就计划好了。她明白，自己只是他计划里的一环。她意识到，这场婚姻从头到尾都是骗局。
- ✅ 她把那份合同翻到最后一页。签名日期是去年三月。那时候，他还在跟她商量蜜月去哪里。

**改法**：删掉“她知道/她明白/她意识到”，把判断落到证据上。

### 3.6 每段开头先总结

- ❌ 不难看出，他已经下定决心。接下来，他走向了马厩。
- ✅ 他走向马厩，没有回头。

**改法**：段落的第一句必须是动作、感知或对话，不是评论。

### 3.7 比喻成灾

**标准**：每千字比喻标记（像/好像/仿佛/宛如/如同/犹如）≤8 个；一段最多 1 个。

**改法**：不是把“仿佛”换成“好似”，而是**删掉比喻，写本体**。保留的比喻要满足三条：具体、意外、符合视角人物的认知（程序员不会用“绣花”打比方）。

### 3.8 声音反差腔 / 预告收尾

- ❌ 他的声音不大，却带着不容置疑的力量。
- ✅ 他一开口，包间里转盘停了。二姑把刚夹起来的海参放回盘子里。
- ❌ 没人知道，这一切才刚刚开始。
- ✅ 她把门带上。楼道声控灯亮了一下，又灭了。

**改法**：写声音落进场子的具体效果；结尾停在一个动作/画面上，不替读者预告。

## 四、段层：打破“列车时刻表”

### 4.1 均匀段

AI：每段 3–4 句，长度差不多。
人：1 句段、5 句段、2 句段交错。

**自检**：连续 3 段长度差不超过 10 字，就要打散。打脸、心死、反转处，允许单句成段。

### 4.2 长段

手机阅读，单段超过 150 字就该按“镜头/新动作/新线索/视线切换”断段。不是按句号断，是按**画面换了没有**断。

### 4.3 动作清单

- ❌ 他起身，走到窗边，拉开窗帘，点了一支烟，深吸一口，缓缓吐出。
- ✅ 他走到窗边，点了烟。窗帘没拉，对面楼的灯正好灭了一层。

**改法**：删掉无功能的步骤，只留有情绪/情节功能的动作；用环境反馈做缓冲。

### 4.4 只有叙述，没有留白

真人写作敢“不解释”。该留白的地方：

- 人物为什么突然沉默；
- 一个反复出现的物件；
- 一句没头没尾的话；
- 一个没有下文的眼神。

**注意**：留白不是故弄玄虚。前文要给够线索，读者回看能拼出来。

### 4.5 全对话 / 全叙述

全对话像剧本，全叙述像报告。每 3–5 行对话，插一个动作、环境或心理；每段叙述，至少有一句人声。

## 五、内容层：七个“不像人”的根

词句可以骗人，内容骗不了。逐节问：

1. **谁想要什么？** 这一节的主角有没有一个具体目标？没有，就是水文。
2. **她做了什么不可逆的选择？** 只是“心里难受/暗暗发誓”，不算。
3. **什么变了？** 证据、关系、风险、资源、决定，至少一个。
4. **哪个细节只有这个故事才有？** 职业动作、方言、旧物、具体金额、家人的怪癖。
5. **叙述者有没有偏见/盲区？** 她会不会误会、嘴硬、自我欺骗、迁怒？
6. **有没有生活噪音？** 物业群、外卖迟了、药盒、孩子的作业、邻居的电钻。
7. **有没有代价？** 身体疼、钱少了、关系断了、名声坏了。没有代价的胜利是意淫。

### 人物同声测试

遮住名字，随机抽三段对话。能认出谁在说吗？不能，就给每个人一个**语言习惯**：

- 句长：有人只说短句，有人爱绕；
- 称呼：有人叫全名，有人只叫“哎”；
- 口头禅：不要每句都带，关键时刻带一次；
- 知识边界：护士会说“留置针”，不会说“静脉通路建立”。

### 因果太顺

AI 的情节像 DOM 树：A 导致 B，B 导致 C，每一步都合理。真人生活里有**意外、拖延、办错、走神、别人不配合**。

不是让你加随机事件，是让主角的每一步都遇到**具体的摩擦**：去银行没带身份证、录音被电话打断、证人临时改口、电梯坏了。

## 六、人味八法（正向写法）

1. **具体锚点**：地名、金额、时间、品牌、职业动作。每 1000 字至少 3 个。
2. **物件回环**：开篇的婚戒/旧手机/一碗汤，结尾再出现一次，意义变了。
3. **叙述者偏见**：她会把婆婆的每句话都往坏处想；她会给自己的刻薄找理由。读者不一定同意她，但会相信她。
4. **生活噪音**：主线之外的一两句“没用的事”，让人物活在世界里。
5. **不完整对话**：打断、答非所问、沉默、说错话再改口。
6. **身体代价**：疼、饿、困、手抖、想上厕所、鞋子磨脚。身体不会因为剧情紧张就消失。
7. **留白**：不解释动机，不解释每一个眼神，让读者参与。
8. **不匀称**：有的地方写很细，有的地方一句带过。真人不会平均用力。

## 七、两遍法（执行顺序）

### 第一遍：机械遍（30 分钟）

1. 跑扫描器：

```bash
# 在 skill 根目录执行；当前目录不是 skill 根目录时，换成脚本绝对路径
python scripts/check_ai.py 正文.txt --min-words 6000
```

2. 按报告从重到轻改：阻断项 → 高频建议项 → 密度项。
3. 每条只做“三换”：换抽象为物件、换判断为动作、换总结为下一件事。
4. 改完再跑一次，直到无阻断、指数 ≥75。

**不要**：为了清零把有功能的强情绪句全删；不要用同义词轮换骗过词表。

### 第二遍：语义遍（逐节）

对每一节问“语义十问”：

1. 这一节谁想要什么？要不到会怎样？
2. 主角做了什么选择？代价是什么？
3. 这一节结束时什么变了？
4. 哪个细节是这篇独有的？
5. 叙述者的偏见/盲区在哪里？
6. 有没有生活噪音或身体感？
7. 对话有潜台词吗？去掉名字能认出人吗？
8. 反转的伏笔，回看能找到两处吗？
9. 有没有一段是在“解释”而不是“发生”？
10. 最后一段是在讲故事，还是在讲道理？

**任何一问答不上来，重写那一节，不要全局润色。**

### 第三遍：朗读遍（10 分钟）

出声读。卡住的地方、想跳过的地方、读起来像新闻联播的地方，就是要改的地方。

**删 10%**：第一遍删形容词和解释，第二遍删重复的情绪，第三遍删“其实可以不写”的过场。

## 八、五组对照（照这个手感改）

### 例 1：情绪直述 → 动作 + 物件

❌ AI：
> 我感到一阵撕心裂肺的痛，泪水不受控制地涌了出来，仿佛整个世界都抛弃了我。

✅ 人：
> 我把他的衬衫从衣架上取下来，闻到一股陌生的洗衣液味。不是我买的。我站在阳台上把它剪了，剪到第三刀，手开始抖。

**诊断**：AI 句在“报告情绪”；人句在“做事”，情绪由读者自己得出。注意“剪到第三刀”有代价感。

### 例 2：不是A而是B → 两个证据

❌ AI：
> 这不是一场普通的婚礼，而是一场精心设计的骗局。

✅ 人：
> 婚礼进行到一半，我才发现迎宾牌上的新娘名字被换过。底下那层没撕干净，露出一个“周”字。

**诊断**：删掉“不是/而是”的判断，让物证说话。

### 例 3：对话标签 → 动作

❌ AI：
> “你走吧。”她淡淡地说道，语气中带着一丝不易察觉的悲伤。

✅ 人：
> “你走吧。”
> 她去开窗，窗框卡住了，推了两下没推动。

**诊断**：动作替代标签；“推不动窗”比“悲伤”具体，也比“悲伤”更悲伤。

### 例 4：结尾升华 → 下一个动作

❌ AI：
> 这一刻，她终于明白，女人只有靠自己，才能掌握自己的人生。

✅ 人：
> 她把钥匙放在鞋柜上，拍了张照，发给中介。然后下楼，买了两个肉包，坐在马路牙子上吃完。

**诊断**：不总结，用“吃包子”这个具体动作收；读者自己会明白她决定了什么。

### 例 5：均匀段 → 长短交错

❌ AI：
> 她走进房间，看到桌上放着一份文件。她拿起来翻了几页，脸色渐渐变了。她没有想到，丈夫竟然瞒着她做了这样的决定。她感到一阵眩晕，扶住了桌角。

✅ 人：
> 桌上放着一份文件。
> 她翻到最后一页。签名是她的名字，日期是上周三。
> 上周三她在医院陪床。
> 她把文件放回去，又拿起来，对着光看那个签名。墨迹是新的。

**诊断**：短段制造停顿；“对着光看墨迹”是具体动作，也是怀疑的开始。

## 九、分题材校准

| 题材 | 可以保留的“AI 感” | 必须压掉的 | 注意 |
|---|---|---|---|
| 世情/追妻 | 强情绪词、审判金句、心死定格 | 重复抒情、空泛控诉、反派降智 | 爽点要当众兑现；女主不能只会哭 |
| 悬疑 | 克制的叙述、冷静的判断句 | 比喻堆叠、故弄玄虚、幻觉收尾 | 线索要公平；警察不能全程消失 |
| 甜宠 | 少量心理独白、心动比喻 | 工业糖精、每段都脸红、男主只会壁咚 | 心动要落在具体事件上 |
| 民俗/怪谈 | 规则条文的公文腔（载体内部） | 叙述者也打官腔、只吓不破 | 规则要具体到动作；破局靠民俗逻辑 |
| 脑洞 | 设定说明（≤500 字） | 设定反复解释、规则随剧情改 | 用场景演示规则，不用旁白讲课 |

**总原则**：题材承诺优先。番茄世情需要直给、需要强情绪、需要“审判句”，这些不是 AI 味；**空洞、重复、没有具体处境的强情绪**才是。

## 十、分寸：别把“去 AI”做成另一种模板

- **不要为了“像人”加错别字/病句**。编辑看到的是不专业，不是真实。
- **不要把所有句子改成短句**。长短交错才是人；全短是电报体。
- **不要给每个人加怪癖**。一个主角有一个具体习惯，比全員怪咖更真。
- **不要删掉所有总结**。真人也会总结，只是总结前有足够的具体内容，总结后不再重复。
- **不要用“方言/脏话”当人味**。除非它属于人物，否则是表演。
- **不要为了躲检测改人名、改数字、加无意义语气词**。这是伪造，不是写作。

## 十一、一页检查表（打印版）

- [ ] 开篇 300 字有事件、有赌注、有反常？
- [ ] 每节结束时，证据/关系/风险/资源/决定至少一个变了？
- [ ] 主角做过至少一个不可逆的选择？
- [ ] 反转回看能找到 2 处伏笔？揭示后有结算？
- [ ] 每 1000 字有 3 个具体锚点（地名/金额/物件/职业动作）？
- [ ] 情绪直述后面接了具体动作，且没有重复解释？
- [ ] “不是A而是B”、三连排比、否定排比，清了吗？
- [ ] 比喻每千字 ≤8，一段 ≤1？
- [ ] 连续 3 段长度不雷同？单段 ≤150 字？
- [ ] 对话去掉名字能认出人？有潜台词？
- [ ] 结尾没有人生总结/命运预告？
- [ ] 扫描器无阻断，模板腔指数 ≥75？
- [ ] 朗读一遍，没有想跳过的地方？

---

**最后一句**：去 AI 味不是把文章改“脏”，是把它改“具体”。具体的疼、具体的钱、具体的一句话说不出口——这三样有了，AI 味就待不住。
