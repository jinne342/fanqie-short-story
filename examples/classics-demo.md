# 名著仿写示例：县城相亲角

> 演示“检索 3 张卡 → 取 3 个动作 → 换表面 → 反抄检查”，不是让模型背整本书。

## 1. 检索

```bash
python scripts/classics_index.py seed --query "冷眼 婚姻 开头" --limit 5
```

命中：

- 《孔乙己》鲁迅 [视角]：小伙计视角，冷眼看、不解释，留白即批判。
- 《倾城之恋》张爱玲 [人物]：白流苏出场在娘家客厅的算计里，婚姻市场即人物处境。
- 《呼兰河传》萧红 [场景]：从“严冬”和大地的裂口写起，环境即命运。

## 2. 只取三个动作

1. **物件开场**：不写“她很焦虑”，先写照片、伞、鞋。
2. **婚姻市场**：把“属相、价格、老实”这些算计放进旁人的嘴。
3. **冷眼叙述**：叙述者不替人物哭，也不解释她为什么难受。

## 3. 换表面：县城相亲角（约 300 字）

相亲角在人民公园西门，第三棵梧桐下面。她妈把她的照片塑封了两份，一份压在伞面上，一份攥在手心，见人就递。照片是前年拍的，脸上还有一点肉。她把伞往树荫里挪，听见旁边一个阿姨说：“属羊的不要，属羊的命苦。”

她低头看自己的鞋。鞋是新的，三十八块，夜市买的，走两步就磨脚。

她妈替她答话：“我们家的姑娘，老实。”

“老实好。”阿姨说，“老实的不挑。”

她把伞面上的照片翻过去。背面用圆珠笔写着一行小字：1993 年，冬。字是她妈写的，写得很用力，纸都凹下去了。

她没有说话。她只是把伞又往树荫里挪了一点。太阳移过来，正好照在照片上，把她自己的脸照得发白。

## 4. 反抄检查

```bash
python scripts/classics_index.py similarity --against 原文片段.txt --file 本节选.txt --threshold 12
```

示例文本为原创，未复用《倾城之恋》《孔乙己》《呼兰河传》的句子、专名和情节链。检查重点：

- 没有 12 字以上连续重合；
- 没有“白流苏/鲁镇/呼兰河”等专名；
- 没有搬“娘家客厅算计/咸亨酒店/严冬大地”的原情节。

## 5. 交付标注

