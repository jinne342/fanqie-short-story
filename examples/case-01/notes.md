# 案例 01：满月宴上的陪嫁房

> 用途：看“同一场戏，AI 默认写法”和“人味写法”的差别。两版都不是完整短篇，只是开篇 700 字左右的样章；完整 1.2 万字还要接“抵押—反打—清算”。

## 设定

- 题材：世情打脸
- 主情绪：爽感释放 + 一点寒意
- 人称：第一人称
- 目标篇幅：1.2 万字（本样章约 700 字）
- 核心冲突：婆婆在满月宴上宣布，把女主的陪嫁房给小叔子当婚房
- 女主底牌：房本、赠与合同、公证书一直在她手里；丈夫已经偷拿她身份证去办过抵押

### 标题候选

1. 《满月宴上，婆婆把我的陪嫁房给了小叔子》
2. 《房本在我妈保险柜里，你们谁见过？》
3. 《丈夫拿我身份证抵押那天，我去补了公证书》

### 简介

> 满月宴二十八桌，婆婆当众宣布，把我的陪嫁房给小叔子当婚房。
> 亲戚都夸她明事理，丈夫低头吃鱼，一句话没说。
> 他们不知道，房本上只有我的名字。
> 更不知道，我等的就是今天。

## AI 稿诊断（`ai-draft.txt`，指数 25 / D）

| 问题 | 原文 | 为什么假 |
|---|---|---|
| 天气/灯光开场 | “灯火辉煌的夜晚，水晶灯璀璨夺目，空气中弥漫着饭菜的香气” | 信息量为零，换个酒店也成立 |
| 情绪直述 | “感到一阵莫名的疲惫”“感到一阵愤怒，心中涌起一股难以言喻的委屈” | 报告情绪，不写处境 |
| 套式动作 | “缓缓站起身”“淡淡地说道”“嘴角微微上扬”“深吸一口气” | 动作是通用标签，不属于这个人 |
| 不是A而是B | “这不是一场普通的满月宴，而是一场精心设计的鸿门宴” | 作者替读者下判断，且没有证据 |
| 解释链 | “我知道，这意味着……我明白……我意识到……” | 连下三个判断，没有一个是动作 |
| 三连排比 | “失去了爱情，失去了家庭，失去了尊严” | 抽象、可替换、无具体损失 |
| 结尾升华 | “这一刻，我终于明白……”“没人知道，这一切才刚刚开始” | 替读者总结 + 预告，短篇大忌 |

## 人味稿做了什么（`human-draft.txt`，指数 100 / A）

| 改动 | AI 写法 | 人味写法 |
|---|---|---|
| 开场 | 酒店灯光、饭菜香气 | 酒店名、二十八桌、刀口疼、椅子硬——**身体先在场** |
| 赌注 | “陪嫁房”三个字 | 滨湖、八十九平、2019 年全款一百二十六万、房本一个名字 |
| 羞辱 | “亲戚们纷纷点头称赞” | 二姑说“明事理”，三叔说“一家人不说两家话”，丈夫给婆婆夹鱼 |
| 情绪 | “感到愤怒/委屈” | 给孩子擦奶渍，擦了两下没擦掉，干在上面了 |
| 底牌 | “我不能再软弱下去了” | 牛皮纸袋、白线缠两圈、公证书第二页、转盘上轻轻一转 |
| 对话标签 | “她淡淡地说道” | 动作代替标签：敲转盘、推纸袋、倒水、手抖洒在桌布上 |
| 结尾 | “这一切才刚刚开始” | “先吃饭。鱼凉了。”——动作收，不解释 |

### 关键改法（可复用）

1. **把“情绪”换成“手上的事”**：擦奶渍、倒水、转纸袋、夹鱼。读者从动作里读情绪。
2. **把“判断”换成“证据”**：不写“他们早就计划好了”，写“你拿我身份证去办抵押那天，我去补的”。
3. **把“排比”换成“账单”**：不写“失去一切”，写“一百二十六万、八十九平、三千八的饭钱”。
4. **把“升华”换成“下一件事”**：不写“我终于明白”，写“先吃饭，鱼凉了”。

## 扫描器看不到的（必须人工判断）

- **赌注够不够狠**：房子是婚前全款、赠与个人，法律上站得住；但读者要的是“她当众被剥夺”的窒息感，所以宴席、亲戚、丈夫的沉默必须写足。
- **反转公不公平**：这一版只埋了“房本/抵押/公证书”三条线；完整篇还要在开篇 500 字内补一处“丈夫翻她包”的细节，后文揭示他在找房本。
- **人物可不可信**：婆婆不是纯恶，她要的是“小儿子结婚 + 大家庭面子”；丈夫不是纯怂，他怕的是“他妈当众下不来台”。反派有理由，打脸才疼。
- **结尾有没有余味**：这一版停在“鱼凉了”，是冷幽默；完整篇的结尾要再翻一次（比如丈夫半夜去翻保险柜，发现里面只有一张她留的离婚协议）。

## 怎么复用这个案例

- 写世情打脸：先列“损失账单”（房、钱、孩子、脸面），再挑一个**当众发生**的场合。
- 写开篇：第一段让身体在场（疼、累、冷、饿），第二段让冲突发生，第三段让读者看见底牌的一角。
- 改 AI 稿：先跑 `python scripts/check_ai.py`，按“阻断 → 高频建议”改；改完再问语义十问。
- 不要照抄句子。抄结构：**身体在场 → 当众剥夺 → 一个具体物证 → 动作收尾**。
